Access and repeatability

The sign-in form provides the public synthetic evaluation account. Its default isolated rehearsal has independent stock and a two-hour lifetime. Use its workspace email on Android to share the same stock; the public evaluation password remains the same. Three concurrent rehearsals and a database-size guard protect the Free plan. The shared workspace remains available if rehearsal capacity is reached.

The static review page is available independently of the API. The Free backend may need about a minute to wake; a scheduled readiness check is best-effort. Allow the sign-in request to finish and retry if needed. The downloadable evidence supports review if the API is unavailable.

Data and operating limits

The dynamic operating dataset contains 48 distributor–medicine requested-demand series over 260 weeks, plus sales measures and zero-demand warehouse records for stock accounting. It contains 218,400 long-format measurement rows in total. Public pharmacy categories are kept separate from the operating ledger.

The inventory evaluation uses recorded chronological sales and forecasts with 200 paired logistics seeds. Supply capacity, lead times and shelf lives are assumptions. Buffers are selected on calibration; service targets can fail on test. Neither the operating generator nor this replay establishes real company inventory savings.

The team developed the project with AI-assisted implementation and documentation. Significant third-party datasets and software retain their notices.
